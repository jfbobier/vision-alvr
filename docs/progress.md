### Foveation and NVENC options (design notes, 2026-10-08)
Foveation parameters stay in `session.json` (`session_settings.video.foveated_encoding`: `center_size_x/y`, `center_shift_x/y`, `edge_ratio_x/y`), not in the NVIDIA profile; the harness baseline fixture holds your values. |---|---|---|---|
| 4, 5 | 4224x1664 | 30.9% | +0% |
| 3, 3.5 | 4544x1856 | 37.1% | +20% |
| 2.5, 3 | 4800x1952 | 41.2% | +33% |
| 2, 2.5 | 5184x2048 | 46.7% | +51% |

Candidate refinement (prototype implemented, see the QP map row above): keep a milder warp (about +30% pixels) and add an NVENC QP-delta map (`NV_ENC_QP_MAP_DELTA`, per-CTB `qpDeltaMap`; the vendored SDK 12.2 header says the *emphasis* mode is H.264-only, so HEVC needs the delta mode) so bits go to the center.
